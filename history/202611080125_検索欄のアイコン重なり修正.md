# 検索欄のアイコン重なり修正（あわせて、入力必須の判定場所を回答）

## 概要
- ユーザーの依頼（`prompt/修正依頼(Claude).txt`）
  1. 入力必須・任意は、どこで設定・判断しているか（質問）
  2. 発注先・納入先をマスタから選ぶとき、入力した文字が虫眼鏡アイコンに重なって見づらい（不具合）
- 計画を示し、ユーザーの承認を得て実施した。

## 1. 入力必須・任意の判定場所（回答。コードの変更なし）
| 役割 | 場所 |
|------|------|
| 画面の表示だけ | gas_app/index.html の各ラベルのバッジ（`badge-required`・`badge-optional`）。判定には使わない |
| 実際の判定 | gas_app/Code.gs【Validator】`validateRequest` の `req(...)` など |
| チェックの強さ | gas_app/Code.gs `checkLevelFor_`。一時保存は FORMAT（必須を見ない）。入力完了・承認依頼は FULL（必須も見る）。入力完了・承認依頼中・承認済の修正も FULL。承認時も FULL で確かめる |
| 画面への表示 | gas_app/js.html `showFieldErrors`。画面では判定せず、サーバーのエラーを出すだけ |
| 仕様書 | docs/04_実装仕様.md 第1部 §4.1 |

- 必須の項目: 部門・種別・承認者・発注先・納入先（区分と、区分に応じてコードか名称）・購入物品名・数量・理由
- 任意の項目: 型番・単位補足・納品日・添付
- 設定シートでは変えられない。変えるときは、Code.gs の `req`、index.html のバッジ、docs/04 §4.1 をそろえて直す。

## 2. 不具合の原因と修正
- **原因**: CSS の優先順位。
  - 検索欄の左の余白は `.input-with-icon input { padding-left: 2.35rem; }` で取っている。
  - 検索欄は `.form-group` の中にあるため、より強い指定 `.form-group input[type="text"]` の `padding: 0.65rem 0.85rem` が勝っていた。
  - その結果、左の余白が狭くなり、文字がアイコンの下から始まっていた。
- **影響した場所**（3か所）
  - 新規入力の発注先検索
  - 新規入力の納入先検索
  - コード補完ダイアログの取引先検索
- **修正**: gas_app/css.html の該当行を `.input-with-icon input, .form-group .input-with-icon input { padding-left: 2.35rem; }` にした（1行）。

## 確認結果
- ヘッドレス Chrome で検索欄に文字を入れ、3か所とも左の余白が 37.6px（2.35rem）になることを確認した。文字はアイコンの右から始まる。
