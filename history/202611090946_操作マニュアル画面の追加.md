# 操作マニュアル画面の追加

## 概要
- ユーザーの依頼（`prompt/修正依頼(Claude).txt`）: 操作マニュアル画面を追加したい。デザインなどは「01.エネルギー使用量集計」のマニュアル画面を参考にする。
- 計画を示し、承認を得て実施した。

## 機能（変更内容）
- **マニュアルの開き方**
  - 画面右上に「マニュアル」ボタンを追加した。押すと、別のタブでマニュアルを開く。
  - GAS では、`doGet` が URL の `?page=manual` を見て、HTML ファイル `manual` を返す。公開 URL は、新しく作った `getAppUrl()` で取る。
  - ローカルの local_preview.html では、`gas_app/manual.html` を開く。
- **マニュアルの紙面**
  - 参考アプリと同じ作りにした。
    - 左に追従する目次（印刷 / PDF のボタン付き）と、右の本文
    - 図と、図の番号（赤い丸）に対応する説明の表
    - 画面の文言の札、注意書き、FAQ
    - 印刷用と、狭い画面用の CSS
  - 色はこのアプリの値にした。
  - 目次
    1. システム概要と画面構成
    2. 操作者と暗証番号
    3. 新規入力
    4. 入力データ一覧
    5. 承認者の操作
    6. 承認済一覧
    7. システム反映済一覧
    8. 管理者編
    9. 付録・FAQ
  - 図は16枚。どれも、説明する箇所に赤枠と番号を付けた。
- **作り方**（参考アプリと同じ）
  - 原本は `gas_app/manual.template.html`、図は `gas_app/manual_images/` にある。
  - `node tools/build_manual.js` が図を base64 で埋め込み、`gas_app/manual.html` を作る（645KB）。
  - `node tools/capture_manual_screenshots.js` が、local_preview.html をヘッドレス Chrome で開き、各場面を撮る。
    - 場面は、URL のハッシュ（tab= op= auth= rows=）と画面の関数で作る。
    - プレビューのバナーは隠して撮る。
  - `tools/browserDriver.js` は、参考アプリのものを写した。変えたのは、待ち合わせの判定（読み込み中の表示の id）と、通知の記録だけ。

## 不具合の修正（付随）
- フェイクの Range に `insertCheckboxes` が無く、撮影のときに警告が出ていた。何もしない `insertCheckboxes` を追加した（`tools/gas_fakes.js`）。

## デザインの調整
- マニュアルを幅900px以下で表示したときに、表の「名称」列の幅を固定しないようにした。固定したままだと、スマホで説明の列が細くなりすぎるため。

## 確認結果
- テスト（`node tools/run_tests_node.js`）: 全件 OK
- 撮影: 16枚、計444KB。赤枠と番号の位置を目で確かめた。
- manual.html を確認した。
  - 1280px で、目次・本文・図が表示される。
  - 目次のリンクで、その章へ移動する（6.2 へ移動したことを確認）。
  - 幅375pxで、横スクロールが出ない。
- local_preview.html の「マニュアル」ボタンを押すと、`gas_app/manual.html` が開く（読み込みも成功した）。
- スクリーンショット: `screenshot/202611090946_操作マニュアル画面の追加/`
  - 41: 先頭
  - 42: 6.2 へ移動したところ
  - 43: 幅375px

## GAS 開発環境への反映
